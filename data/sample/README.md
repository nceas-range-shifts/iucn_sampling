# Sample data (synthetic)

Every file in this directory is **synthetic**, generated by
[`make_sample_data.R`](make_sample_data.R) with a fixed random seed. It exists
only so the pipeline can run end-to-end offline (no API keys, no downloads).

- **Species names are real**, but nothing else here is: each "range" is a random
  0.4° × 0.4° box, and the "GBIF" occurrences are randomly placed points
  (`datasetKey = "sample"`, fabricated `gbifID`s).
- It is **not** CDFW/CWHR range data and **not** real GBIF records.

**Do not analyze or cite this data as real observations, real species ranges, or
real GBIF/CDFW data.** To regenerate it: `Rscript data/sample/make_sample_data.R`.

For a real analysis, supply your own inputs — see
[`../../docs/adapting-to-your-data.md`](../../docs/adapting-to-your-data.md) — and
cite the sources you use (see **Data sources & citation** in the
[project README](../../README.md)).
